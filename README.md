# Bloomie

面向学龄前儿童照护者的家庭支持 Web App。第一版包含「聊一聊」「小小书架」「今天一起」「找到支持」，使用同一套现代拟物化设计。

基于 [官方 Next.js + Supabase starter](https://vercel.com/templates/next.js/supabase)，保留 Supabase SSR 会话能力。界面使用 React、TypeScript、Lucide 与自定义 CSS；无需外部字体和图片服务。暂定名称可以更换。

## 首次上线

按 [部署指南](DEPLOYMENT_GUIDE.md) 配置 Supabase 数据库、邮件与管理员，再通过 GitHub 部署到 Vercel。当前云端数据库与真实登录仍待验收；本机预览通过不代表公开 AI 已可上线。完整代码检查使用 `bun run check`。

## 本地运行

```sh
bun install --frozen-lockfile
bun run dev --hostname 127.0.0.1
```

打开 http://127.0.0.1:3000 。无需任何密钥即可体验本地版。

```sh
bun run typecheck
bun test
bun run build
bun start
```

生产构建使用 Webpack，避免此桌面沙箱中 Turbopack 构建进程的端口权限问题；开发预览使用 Turbopack。

## 接入 Supabase

真实连接检查结果、邮件模板和上线验收步骤见 [登录配置指南](LOGIN_SETUP.md)。公开邮箱登录需要可向普通用户发送邮件的 SMTP 服务。

1. 在独立项目的 SQL 编辑器依次应用 `supabase/migrations/202610090001_initial.sql` 与 `supabase/migrations/202610090002_speech_quota.sql`、`supabase/migrations/202610090003_research_library.sql`。迁移创建用户隔离的 favorites 表与服务端日额度函数；不保存会话内容。
2. 将 `.env.example` 复制为 `.env.local`，填写 `NEXT_PUBLIC_SUPABASE_URL` 与 `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`。不需要 service-role 密钥。
3. 在 Supabase Auth 中配置站点 URL；把本地与 Vercel 的 `/auth/callback` 加入允许的 Redirect URLs，启用邮箱登录。不要使用不受限制的生产通配符。
4. 重启开发服务。用邮箱链接登录并验证两名不同用户无法读写彼此收藏；退出后回到本地书架。本地收藏不会自动上传。
5. 用真实项目验证登录、链接过期、RLS、云端读写失败及跨账户切换。当前自动测试不代表迁移已经在远端执行。

## 接入 OpenAI

先阅读 [API 接入指南](API_SETUP.md)。已准备 `.env.local` 空密钥文件，供私人本机试用：`AI_ENABLED=true`、`TTS_ENABLED=true`、`LOCAL_AI_PREVIEW=true`，但没有密钥时仍是演示。

真实聊天使用账户可用的 `OPENAI_MODEL`；默认 `gpt-4.1-mini` 支持 Responses 与结构化输出。自然语音默认 `gpt-4o-mini-tts` 与 `marin`，可在环境变量改成 `cedar`。声音偏好是产品设定，实际跨语言音质需用户试听；官方说明声音主要针对英语优化。

`LOCAL_AI_PREVIEW=true` 只允许非 production 的 localhost / 127.0.0.1 / ::1 请求，用于负责人私下测试，不要求 Supabase 登录或把内容标成已复核。公开域名与 Vercel production 都忽略这个例外。开发服务器绑定 `127.0.0.1`。公开使用同时要求 `CONTENT_REVIEWED=true`（实际完成专业复核后才填写）、Supabase 配置、登录与数据库额度。聊天可直接发送；音频生成仍需勾选语音同意。聊天每日 30 次，音频每日 20 次；UTC 数据库日期计数。

密钥只有服务端能读取。不要发送到聊天框或提交到 Git。没有配置时显示演示；真实服务启用后显示 AI 回答，供应商失败明确报错，不伪造成功。关闭一个服务不会影响另一个。保留真人服务演示和 AI 生成语音说明。

音频仅允许内置文章 ID，由服务器取得当前语言的文章，拒绝客户端任意文本；不把聊天内容发送到语音接口。浏览器当前会话最多缓存 8 段音频，重复播放复用；关闭阅读、换语言或退出页面停止播放，取消生成会中止请求。无数据库音频保存、无浏览器设备声音回退。

使用官方 Responses API，`store:false`；这不等于供应商零保留承诺。不要把生产日志或第三方观测系统配置为记录请求正文。请求与输出调用 Moderations，任何检查失败都不返回生成内容。附加规则覆盖部分五种语言的危险表达，不能替代风险评估，也可能误判或漏判。来源 ID 只能来自内置目录；引用存在不保证所有生成断言正确，因此正式试用前仍需人工抽样核验。

当前不启用开放网络搜索，不提供诊断、处方或量表判断。资料覆盖有限。紧急风险不走预约演示，展示当地紧急服务求助说明；没有真人实时监看。

## Vercel

项目是标准 Next.js 服务端应用，不能用静态导出替代 API。

1. 将代码放入自己的 GitHub 仓库，导入 Vercel；选 Next.js。
2. 安装命令 `bun install --frozen-lockfile`；构建命令 `bun run build`。
3. 在相应环境设置变量。OpenAI 密钥仅服务端；公开预览环境保持 AI 与 TTS 开关关闭，并关闭 LOCAL_AI_PREVIEW。Supabase 的 NEXT_PUBLIC 变量变化后重新构建。
4. 配置 Supabase 回调地址，验证登录与云端收藏，再验证 AI 额度、审核失败和来源展示。
5. 在南京手机网络与微信浏览器实测访问、字体、自然语音、登录与速度；本地测试不代表大陆网络可用性。

本次仅完成本地搭建，没有创建远端 Supabase 项目、GitHub 仓库或 Vercel 部署。

## 聊天语音输入
空输入框显示麦克风：按住录音、松开编辑，上滑松开转写后发送，左滑或 Escape 取消。支持说话语言自动识别，不跟随界面语言强制翻译。使用 OpenAI `/v1/audio/transcriptions`，默认 `gpt-transcribe`；需要 `STT_ENABLED=true` 和现有服务端密钥。音频和文本不持久化，最长录音 60 秒、上传 3 MiB。公开部署要求 HTTPS、Supabase 登录和已启用的语音额度；与听书共用迁移 002 的每天 20 次额度。本机已验证五种语言的真实 API 转写，录音交互用合成语音输入验证；实际手机麦克风权限及音质仍应实机验收。配置详见 `API_SETUP.md`。

每日活动和家庭聚会的配置、记录范围与提醒说明见 [今天一起配置指南](TOGETHER_SETUP.md)。这些功能无需新增 API。

「今天一起」和「每周家庭聚会」已接入内容工作室。儿童年龄、完成记录与小记录继续只保存在浏览器；聚会 RSVP 独立保存在服务器，管理员可查看、用户可以取消。见 [后台接入步骤](ADMIN_SETUP.md)。
